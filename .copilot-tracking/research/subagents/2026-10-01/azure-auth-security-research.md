* What framework, runtime, application shape, storage API, and Azure hosting model does the upstream repository currently use or explicitly target?

* Which HTTPS, CORS, CSRF, security-header, logging/PII, least-privilege, and local-development controls apply?
* Which approach best fits a secure workshop while preserving the repository's intended learning scope?
